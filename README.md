A tiny orange fox slips into a moonlit lantern garden at night. Stone lantern-keepers patrol the paths, sweeping the garden with warm cones of light. Hide behind walls, crates and hedges, melt into moon-bushes, creep into the little shrine, steal the glowing Moon-Pearl, and escape through the Moon Gate unseen — if a keeper's light holds on you and the alert fills, you are caught.

## How to play

- **WASD / Arrow keys** — move
- **Shift** — prowl (slower, harder to spot)
- **R** — restart
- **Click / Enter** — start

Avoid the vision cones, hide in green moon-bushes unless a keeper gets very close, steal the Moon-Pearl from the shrine, then reach the north-east gate. The game is plain static files under `game/` — open `game/index.html` from any static server and play in a desktop browser, no network needed.
